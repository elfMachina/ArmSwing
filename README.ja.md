# ArmSwing

**VRChat のフルトラッキングで、腕を自然に振って歩く。**

[English](README.md) | 日本語 | [한국어](README.ko.md) | [简体中文](README.zh-CN.md) | [Español](README.es.md) | [Português (BR)](README.pt-BR.md) | [Русский](README.ru.md)

VRChat のフルトラッキングでスティック移動すると、体は滑るように進むのに腕は
固まったままになります。ArmSwing は、歩いている間だけ下ろしている腕を
VRChat 自身の歩行アニメーションに任せるので、腕が自然に振れます。手を上げるか、
グリップまたはトリガーを握れば、その腕は同じフレームでコントローラーの動きに
戻ります。

## 必要なもの

- Windows 10（バージョン 1809 以降）または Windows 11、SteamVR
- VRChat（Steam 版）で**フルトラッキングがキャリブレーション済み**であること
  （トラッカー、SlimeVR、Standable など、VRChat がフルボディとして
  キャリブレーションするもの）
- スティック付きのコントローラー（「対応コントローラー」を参照）
- **VRChat の OSC がオン**：アクションメニュー（Action Menu）> Options > OSC > Enabled

フルトラッキングなし（3 点トラッキング）の場合、ArmSwing は腕を通常どおり
トラッキングさせたままにします。3 点トラッキング対応は開発中です。

## インストール

1. SteamVR を終了します。
2. zip 全体を、移動しないフォルダーに展開します（例：`C:\Tools\ArmSwing`）。
   `armswing` フォルダー、`install.bat`、`uninstall.bat`、README ファイルが
   あることを確認してください。
3. `install.bat` をダブルクリックします。
4. SteamVR を起動してから、`armswing\armswing.exe` を実行します。

ウィンドウは開きません。ArmSwing はタスクトレイ（時計の横）で動作します。
終了するにはアイコンを右クリックします。SteamVR を閉じると自動で終了します。

**アップデート：** SteamVR を終了し、新しい zip を展開して、その中の
`install.bat` を実行します。古いコピーの登録は自動で解除されます。その後、
古いフォルダーを削除してください。

**Windows の警告が出た場合：** ArmSwing はまだコード署名されていないため、
`install.bat` や `armswing.exe` の実行時に Windows SmartScreen が
「Windows によって PC が保護されました」と表示することがあります。
**詳細情報** をクリックしてから **実行** をクリックしてください。また、
ドライバーが他の SteamVR ドライバーアドオンと同じ方法で SteamVR に
フックするため、一部のウイルス対策ソフトが検出することがあります。
ソースコードはすべて公開されており、各リリースには SHA-256 チェックサムが
記載されているので、ダウンロードしたファイルが本物か確認できます。

## 使い方

- 腕を下ろしたまま左スティックで歩くと、腕が振れます。
- 腕をおおよそ腰より上に上げるか、グリップまたはトリガーを握ると、その腕は
  歩いている途中でもすぐにコントローラーの動きに戻ります。
- スティックを倒していても VRChat 上で実際に移動していないとき（壁に向かって
  歩く、カメラの飛行モード、着席中、とても低くしゃがんでいるとき）は、腕は
  トラッキングされたままです。
- ArmSwing は起動中、すべての SteamVR ゲームで動作します。他のゲームを遊ぶ前に
  トレイアイコンから終了してください。

## 対応コントローラー

設定不要でそのまま使えるもの：PlayStation VR2 Sense、Meta Quest / Rift の
Touch コントローラー（Quest Link、Air Link、Steam Link、Virtual Desktop、ALVR）、
Valve Index、Steam Frame、Vive Cosmos、HP Reverb G2、Windows Mixed Reality。
Pico と Vive Focus 3 / XR Elite のコントローラー（Steam Link 経由）は、自動的に
Quest 用のプリセットが使われます。

その他のスティック付きコントローラー：SteamVR > 設定 > コントローラー >
コントローラーのバインドを管理 > ArmSwing で、移動用スティックを
`left_stick_pos` に割り当ててください。Vive ワンドは非対応です（スティックでは
なくトラックパッドのため）。

## 自分の環境を確認する

下の表から自分の環境を探してください。設定項目の説明は「設定」にあります。

| あなたの環境 | すること |
|---|---|
| 上のリストにあるコントローラー | 何もしなくて大丈夫です。 |
| その他のスティック付きコントローラー | `left_stick_pos` を割り当ててください（上記参照）。 |
| 手を離せるコントローラー（Globular Cluster などのストラップ、緩めた Index のストラップ） | 任意：`wake_mode=touch` にすると、手がコントローラーに触れている間はその腕が自分のままになります。 |
| 腕を下ろしても振れない | `raise_drop` を小さくします（例：`0.50`）。 |
| 腕を残したいのに振れてしまう | `raise_drop` を大きくします（例：`0.90`）。 |
| フルトラッキングなし（3 点トラッキング） | まだ非対応です。腕は通常どおりトラッキングされます。 |
| 右スティックで移動している | まだ非対応です。 |
| Steam 版以外の VRChat、または VRChat の OSC がオフ | スティックを倒している間は、壁際やメニュー中でも腕が振れます。すべての機能を使うには、Steam 版で OSC をオンにしてください。 |
| インストール先のフォルダー名に特殊な文字がある（絵文字、Windows の言語と違う文字） | `C:\Tools\ArmSwing` のようなシンプルなパスにインストールしてください。 |

## 設定

`armswing\config.txt` をテキストエディターで編集します。VR 中に保存しても
大丈夫です。約 1 秒以内に反映されます。

| 設定 | 既定値 | 内容 |
|---|---|---|
| `raise_drop` | `0.70` | ヘッドセットから何メートル下までを「腕を上げている」とみなすか。小さくすると、腕を残すにはより高く上げる必要があります。 |
| `wake_mode` | `grip` | `grip`：グリップかトリガーを握っていれば、どの高さでも腕は自分のまま。`touch`：タッチセンサーも対象。ストラップなどで手を離せるコントローラーでのみ使用してください。 |
| `wake_hold` | `120` | グリップやトリガーを離した後、腕が自分のままでいる時間（ms）。 |
| `walk_hold` | `90` | 腕が振れ始めるまでにスティックを倒し続ける時間（ms）。スティックの小さなブレを無視します。 |

アンインストールせずに ArmSwing をオフにするには、`armswing\mode.txt` に
`off` と書きます（`9` と書くと元に戻ります）。

## トラブルシューティング

トレイアイコンにマウスを重ねると状態が表示されます。ログは `armswing`
フォルダーにあります：`armswing-watcher.log`（トレイアプリ）と
`armswing.log`（SteamVR ドライバー）。前回のセッションのログは `*.prev` として
残ります。

- **壁際、メニュー中、カメラモードで腕が振れてしまう：** VRChat の OSC が
  オフです。オンにしてください（Action Menu > Options > OSC > Enabled）。正しく
  動作していれば、`armswing-watcher.log` に `VRChat's OSC arriving` と出ます。
- **腕がまったく振れない：** `armswing-watcher.log` に `[stick] action INACTIVE`
  がないか確認してください。お使いのコントローラーに合うバインドがない
  という意味です（「対応コントローラー」を参照）。VRChat でフルトラッキングが
  キャリブレーション済みかも確認してください。
- **片方の腕だけ振れない：** その腕のグリップかトリガーを握っているか、
  手に持つコントローラーで `wake_mode=touch` を使っている可能性があります。
- **それ以外：** Issue を作成し、`armswing-watcher.log` と `armswing.log`、
  それぞれの `.prev` を添付してください。

## 互換性とプライバシー

- **他の OSC アプリ**（VRCFaceTracking など）はそのまま使えます。ArmSwing は
  ポート 9000 と 9001 を使いません。VRChat は OSCQuery で ArmSwing を見つけ、
  ArmSwing 専用のポートに送信します。
- **他の SteamVR アドオン**もそのまま使えます。ArmSwing が変えるのは、歩いて
  いる間に両手がトラッキング中として扱われるかどうかだけです。デバイスは
  追加しません。
- **ネットワーク：** ArmSwing は 127.0.0.1 でのみ待ち受けるため、PC の外部から
  接続されることはありません。VRChat に見つけてもらうため、VRChat や他の
  OSC アプリと同じように、ローカルネットワーク上で mDNS により自身を通知します。
  インターネットには接続せず、データも一切収集しません。

## アンインストール

SteamVR を終了し、`uninstall.bat` を実行してから、フォルダーを削除します。
